# P01 · Disposition criteria

Version 1

## Block

Recommend block when two independent observations corroborate suspected unauthorized activity, such as a novel device and a recipient concentration pattern. Cite each observation and explain the link to the attempt. Avoid double-counting a burst and multiple windows derived from the same burst.

## Release

Recommend release when affirmative historical or contextual evidence explains the alert and significant conflicting evidence has been addressed. Cite the observations that support the benign explanation.

## Escalate

Recommend escalation when evidence is missing, conflicting, or too weak for a supported release or block. Record the follow-up that would resolve the uncertainty.
